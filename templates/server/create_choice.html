Create a new VM on GCP

WG Manager will create a new Compute Engine VM on your GCP project, generate SSH keys automatically, then install and configure WireGuard end to end. No terminal work required.

  • GCP project with billing enabled
  • Service account with Compute Instance Admin role
  • Service account JSON key downloaded
  • Compute Engine API enabled on the project

WG Manager will launch a new EC2 instance on your AWS account, generate SSH keys automatically, then install and configure WireGuard end to end. No terminal work required.

  • AWS account with EC2 access
  • IAM user with EC2 permissions
  • Access key ID and secret key ready
  • Desired region selected
