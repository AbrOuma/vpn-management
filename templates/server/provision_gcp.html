Setup Checklist

Complete these steps in GCP Console before proceeding:

1. Enable Compute Engine API
GCP Console > APIs and Services > Enable APIs > search "Compute Engine API" > Enable
2. Create a Service Account
GCP Console > IAM > Service Accounts > Create Service Account
Grant role: Compute Instance Admin (v1)
3. Download the JSON Key
Click the service account > Keys > Add Key > Create new key > JSON
4. Create a Firewall Rule
GCP Console > VPC Network > Firewall > Create Rule
Protocol: UDP, Port: 51820, Targets: All instances
What Django will do
  1. Generate an SSH key pair
  2. Create the VM via GCP API
  3. Inject the SSH public key into the VM
  4. Wait for the VM to boot and SSH to become available
  5. Install WireGuard and configure IP forwarding
  6. Generate WireGuard keys and write the config
  7. Start the WireGuard service
  8. Store the SSH key so you can download it later
