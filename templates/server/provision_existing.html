What Django will do
  1. SSH into your VM using the key you upload
  2. Run apt-get install wireguard iptables
  3. Enable IP forwarding
  4. Generate a WireGuard private/public key pair on the VM
  5. Detect the VM network interface automatically
  6. Write /etc/wireguard/wg0.conf
  7. Enable and start wg-quick@wg0
  8. Save all details and keys to the database
  9. Populate the IP pool from your subnet
Before you proceed
  • GCP firewall allows UDP port 51820
  • VM is running Debian or Ubuntu
  • SSH user has sudo access
To open the firewall port in GCP:
gcloud compute firewall-rules create wireguard --allow udp:51820 --target-tags wireguard
